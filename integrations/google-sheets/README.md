# ส่งออเดอร์ไป Google Sheets อัตโนมัติ

เว็บจะส่งข้อมูลออเดอร์ไปที่ Google Sheet ทุกครั้งที่:
- ลูกค้าสั่งซื้อ
- ลูกค้าส่งสลิป
- แอดมินเปลี่ยนสถานะหรือบันทึกเลขพัสดุ

หนึ่งออเดอร์ = หนึ่งแถว ถ้าออเดอร์เดิมเปลี่ยน ระบบจะอัปเดตแถวเดิม ไม่สร้างแถวใหม่

Supabase ยังเป็นที่เก็บข้อมูลหลัก ถ้า Google Sheets ล่มหรือตอบช้า การสั่งซื้อยังทำงานปกติ (ระบบรอชีตไม่เกิน 4 วินาที)

## ตั้งค่า (ทำครั้งเดียว ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ เช่นชื่อ "PB3D Orders"
   - **อย่าแชร์ชีตนี้แบบ "ทุกคนที่มีลิงก์"** เพราะในชีตมีชื่อ เบอร์โทร และที่อยู่ลูกค้า
2. ในชีต ไปที่เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ จากนั้นกด 💾 Save
4. ตั้งรหัสลับ:
   - ไปที่ **Project Settings (⚙️) → Script properties → Add script property**
   - Property: `WEBHOOK_SECRET`
   - Value: รหัสสุ่มยาว ๆ สร้างได้ด้วยคำสั่ง `openssl rand -hex 32`
5. Deploy:
   - กด **Deploy → New deployment → ⚙️ Select type → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (เว็บของเราต้องเรียกได้โดยไม่ล็อกอิน ส่วนรหัสลับในข้อ 4 จะกันคนอื่นไม่ให้เขียนข้อมูลได้)
   - กด **Deploy** แล้วอนุญาตสิทธิ์ตามที่ Google ถาม
   - คัดลอก **Web app URL** ที่ได้ (ลงท้ายด้วย `/exec`)
6. ตั้งค่าตัวแปรบน Vercel (Project → Settings → Environment Variables):
   - `GOOGLE_SHEETS_WEBHOOK_URL` = Web app URL จากข้อ 5
   - `GOOGLE_SHEETS_WEBHOOK_SECRET` = รหัสลับจากข้อ 4 (ต้องตรงกันทุกตัวอักษร)
7. Redeploy เว็บบน Vercel
8. ส่งออเดอร์เก่าเข้าชีต: เข้าหน้าแอดมิน แล้วกดปุ่ม **"ส่งออเดอร์ทั้งหมดไป Google Sheets"** (อยู่ใต้ยอด Total Revenue)

## ตรวจสอบ

- เปิด Web app URL ในเบราว์เซอร์ ต้องเห็น `{"ok":true,"service":"pb3d-orders-sheet"}`
- ลองสั่งซื้อ 1 ออเดอร์ แล้วดูว่ามีแถวใหม่ในแท็บ **Orders**

## ถ้าแก้ไข Code.gs ภายหลัง

กด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**

ถ้ากด "New deployment" จะได้ URL ใหม่ ต้องไปแก้ `GOOGLE_SHEETS_WEBHOOK_URL` บน Vercel ด้วย

## ความปลอดภัย

- เว็บส่งรหัสลับไปทุกครั้ง ถ้ารหัสไม่ตรง สคริปต์จะไม่เขียนอะไรลงชีต
- ข้อความที่ลูกค้าพิมพ์ ถ้าขึ้นต้นด้วย `=` `+` `-` `@` ระบบจะเติม `'` ข้างหน้า เพื่อไม่ให้ชีตตีความเป็นสูตร (กัน formula injection)
- ในชีตไม่มีลิงก์สลิป มีแค่ช่อง "สลิป: มี" ส่วนตัวสลิปดูได้จากหน้าแอดมิน ผ่านลิงก์ที่ใช้ได้ 1 ชั่วโมง
